# Olajumoke Medunoye — People Analytics Portfolio

People Analytics | HR Analytics | Workforce Planning

**Live site:** https://olajumokemedunoye.github.io

This is the source for my job-search portfolio. It covers workforce planning, attrition and cost-of-turnover analysis, recruitment analytics and HR reporting automation, built with Power BI, SQL, Excel and Python.

## Featured case studies

| # | Case study | Tools | Type |
|---|---|---|---|
| 01 | Workforce Planning: Replacement Hiring & Attrition Scenarios | Excel, Power BI, DAX | Portfolio project |
| 02 | HR Attrition & Cost-of-Turnover Analysis | SQL, Excel, Power BI | Portfolio project |
| 03 | Recruitment Cost & Hiring Routes | Power BI, Power Query, DAX | Portfolio project |
| 04 | HR Reporting Automation: Performance Dashboard | Power BI, DAX | Portfolio project |

Every case study on the site uses the same structure: business problem, data, analysis, tools, key findings, business implication, recommendation and outcome.

Additional work on the site: Workforce Attrition Risk Modelling (Python, SQL, Power BI), a Customer Service Operations KPI Dashboard, and an illustrative first-year attrition analysis built on synthetic data.

## How results are labelled

The site separates three kinds of evidence:

- **Professional**: work done in paid employment.
- **Portfolio project**: analysis built for the portfolio. Figures are project findings, not employer outcomes.
- **Illustrative**: synthetic data and modelled figures, shown to demonstrate method only.

## Running locally

No build step and no dependencies. Open `index.html` in a browser or serve the folder with any static server. GitHub Pages deploys from `main`.
