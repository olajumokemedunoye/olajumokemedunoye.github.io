|---|---|---|

| TedSquare_Recruitment_Cost.pbix | Recruitment Cost & Hiring Routes | [Report](https://olajumokemedunoye.github.io/projects/recruitment-cost.html) |
| Salford_Performance_Appraisal.pbix | HR Reporting Automation: Performance Dashboard | [Report](https://olajumokemedunoye.github.io/projects/performance-reporting.html) |

The organisations in these files are case-study datasets used for portfolio work. They are not client engagements, and the figures are project findings rather than employer results.
